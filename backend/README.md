# Rental Agreement Risk Analyzer — Backend API

FastAPI backend for the Pune Rental Agreement Risk Analyzer NLP project.

## Endpoints
- `GET /api/health` — health check
- `POST /api/analyze/form` — fill-in-form analysis
- `POST /api/analyze/text` — paste-agreement analysis
- `GET /docs` — interactive API docs (Swagger UI)
